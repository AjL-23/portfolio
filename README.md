## 🚀 Quick Start

### Option 1: Using GitHub Pages (Recommended)

1. **Create a new repository** named `portfolio` on GitHub
   - Go to [GitHub](https://github.com/new)
   - Repository name: `portfolio`
   - Add description: "Cybersecurity Portfolio"
   - Make it Public

2. **Clone the repository** to your computer
   ```bash
   git clone https://github.com/AjL-23/portfolio.git
   cd portfolio
   ```

3. **Copy the files** into your repository
   - Copy `index.html` to the portfolio folder
   - Copy `README.md` to the portfolio folder

4. **Commit and push** to GitHub
   ```bash
   git add .
   git commit -m "Initial portfolio commit"
   git push origin main
   ```

5. **Enable GitHub Pages**
   - Go to your repository settings
   - Scroll to "Pages" section
   - Under "Source", select `main` branch and `/ (root)` folder
   - Click Save
   - Your portfolio will be live at: `https://AjL-23.github.io/portfolio`

### Option 2: Local Development

Simply open `index.html` in your browser to view locally before pushing to GitHub.
